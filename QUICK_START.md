# ⚡ ARIA - Quick Start (2 Minutes)

## 🎯 Get Running in 4 Commands

### 1️⃣ Navigate to project folder
```bash
cd ~/Postmortem
```

### 2️⃣ Install everything
```bash
npm install
```

### 3️⃣ Add your OpenAI API key
```bash
# Copy example file
cp .env.local.example .env.local

# Edit and paste your API key
nano .env.local
```

### 4️⃣ Run the app
```bash
npm run dev
```

### 5️⃣ Open browser
```
http://localhost:3000
```
